# agterm-web

Мобильная веб-панель для сессий [agterm](https://agterm.com): список сессий со статусами агентов,
экран сессии, отправка промптов и быстрые клавиши (Enter, Esc, 1/2/3, стрелки, Ctrl+C).

Сервер слушает только `127.0.0.1`, вход по токену. Чтобы открыть панель с телефона, нужен
свой способ доставить порт 7681 до телефона (например `tailscale serve --bg 7681`, если
Tailscale у тебя работает); без этого с телефона удобнее управлять через Telegram-бота (ниже).

## Установка

Нужны macOS, [agterm](https://agterm.com) с `agtermctl` и Go.

```sh
./install.sh                         # сборка, ~/.local/bin/agterm-web, автозапуск через launchd
~/.local/bin/agterm-web -print-token # токен для первого входа
```

Один раз открой `http://127.0.0.1:7681/?t=<токен>` (или адрес, через который ты пробросил
порт). Дальше токен хранится в cookie. Страницу можно добавить на домашний экран.

## Лимиты

Вверху списка сессий — блок «Лимиты (использовано)»: для каждого Claude-аккаунта из `cswap`
и для Codex — окна «5 часов» и «Неделя», сколько процентов израсходовано и когда сброс по
местному времени («5 часов · 8% · сброс сегодня 18:40»). Цвет: обычный, >70% оранжевый,
>90% красный. Обновляется раз в минуту, пока страница открыта; если обновление не прошло,
внизу блока написано «Не обновлялось N мин».

- Claude: `cswap list --json` (путь — флаг `-cswap`, по умолчанию `~/.local/bin/cswap`).
  cswap сам кэширует данные и не ходит в Anthropic чаще, чем ему положено; сервер
  вдобавок кэширует ответ на 60 с. Замеры старше 15 минут (например, когда cswap пережидает
  429) помечены «~» и «данные от …». Аккаунт с отозванным токеном — «нужен вход (cswap add)».
  Имя аккаунта: алиас (`cswap alias`), название организации или домен почты без зоны
  (`acmemedia`); полная почта не показывается нигде.
- Codex: последнее событие `rate_limits` из `~/.codex/sessions/**/rollout-*.jsonl` за последний
  месяц (флаг `-codex-home`). Числа свежи на момент последнего хода Codex; если ему больше
  10 минут, рядом написано «данные от …».

`agterm-web -limits-json` печатает данные JSON-ом, `agterm-web -limits-swiftbar` — готовое меню
для SwiftBar; оба работают без сервера и токена.

### Строка меню macOS (SwiftBar)

```sh
brew install --cask swiftbar
mkdir -p ~/SwiftBar
ln -s "$PWD/swiftbar/limits.1m.sh" ~/SwiftBar/
```

При первом запуске SwiftBar укажи папку плагинов `~/SwiftBar` (или Preferences → Plugin
Folder). В строке меню — `Claude 6% · Codex 11%`: самое заполненное окно активного
Claude-аккаунта и Codex, цвет по худшему. В меню — все аккаунты и окна. Плагин вызывает
`~/.local/bin/agterm-web -limits-swiftbar` (другой путь — переменная `AGTERM_WEB_BIN`),
поэтому сначала нужна установка через `./install.sh`.

## Telegram-бот

Тот же сервис умеет работать ботом: присылает «🟠 Ждёт тебя» с экраном сессии и кнопками
(1/2/3/Enter/Esc, «🔄 Экран» обновляет то же сообщение, «⌨️ Ещё» — стрелки, Tab, Ctrl+C с
подтверждением), «✅ Готово», а текст из Telegram уходит в сессию. Внизу постоянные кнопки
«📋 Сессии», «📊 Лимиты», «ℹ️ Статус» (`/status`: служба, сессии, связь с Telegram, привязка,
тишина, лимиты), «🔕 Тишина 1ч» / «🔔 Включить».

Лучше всего — группа с темами: у каждой сессии своя тема «DXP · Тесты Price IT». Название
постоянное: задаётся при создании и меняется только при переносе сессии в другой воркспейс (и
при архивации) — статус виден в «📋 Сессии», `/status` и уведомлениях. Пишешь в тему — текст
уходит в эту сессию (в ответ ставится 👌, ошибки пишутся в тему).

**Зеркало разговора Claude Code.** В тему сессии идут: твои промпты, набранные на Mac (👤),
команды `!` с выводом (💻), ответы Claude (🤖, Markdown переведён в оформление Telegram) и
одна строка «🔧 Read auth.go · Bash: go test …» на ход, которая обновляется на месте и в
конце хода показывает итог. Пока ход идёт, строка начинается с «⏳ Работает», промежуточные
тексты (🤖) приходят без звука. Конец хода — последнее сообщение темы: «🏁 Полностью готово ·
2 мин 14 с · 12 действий» с ответом, когда у Claude не осталось фоновых задач (агентов, команд
в фоне, наблюдений Monitor) и он больше ничего не делает, — только оно может прийти со звуком; «✅ Ответ готов ·
в фоне ещё N» — ход закончен, но фоновые задачи ещё идут и Claude продолжит сам, без звука.
Фоновая задача без отчёта о завершении перестаёт учитываться через 2 часа. Мысли, результаты инструментов, субагенты и служебные записи не
пересылаются; промпты, отправленные из Telegram, не дублируются. Для таких сессий отдельное «✅ Готово»
по экрану не присылается (его заменяет 🏁), «🟠 Ждёт тебя» — присылается. Какой разговор к какой
сессии относится, сообщает хук `hooks/claude-session-start.sh` (SessionStart в
`~/.claude/settings.json`); у сессий, запущенных до хука, бот берёт свежий разговор по папке,
если в ней один Claude, иначе `/status` покажет «не зеркалится: перезапусти сессию».

**Файлы, фото, голос, видео.** Присланное в тему сессии (или в личку — в текущую сессию)
сохраняется в `~/agterm-inbox/<воркспейс>/<сессия>/` (0700/0600, старше 7 дней удаляется), и в
сессию уходит строка с путём: «[Фото из Telegram: …] подпись», «[Файл из Telegram: … (имя,
размер)]»; альбом — одной строкой. Голосовое и аудио расшифровываются на Mac (ffmpeg +
whisper.cpp, модель `~/.local/share/whisper/ggml-large-v3-turbo.bin`) и приходят карточкой
«🎙 «текст»» с кнопками ✅ Отправить / ✏️ Исправить / ✖ Отмена. Видео и кружочки уходят сразу:
речь из звуковой дорожки, до 8 ключевых кадров (JPEG ≤1280 px) и подпись. Больше 20 МБ
Telegram боту не отдаёт. Настройки в `telegram-settings.json`: `voiceAutoSend` (false),
`videoAutoSend` (true), `inboxKeepDays` (7), `voiceLanguage` ("auto"); пути к программам —
флаги `-ffmpeg`, `-whisper-cli`, `-whisper-model`.

**Значки тем.** Темы создаются с цветом и значком воркспейса: DXP 💼 синий, EM 🎬 зелёный,
«Своя лига» ⚽️ фиолетовый, GLOBAL 💡 жёлтый, «🚀 Новая сессия» ⚡️ красный, остальные 💬.
Свои — `{"workspaces": {"DXP": {"icon": "💼", "color": "blue"}}}` в `telegram-settings.json`
(цвет задаётся только при создании темы). Архив получает 📁.

**Звук.** Новые сообщения о сессии приходят без звука, пока ты за Mac (agterm видит
активность меньше 15 минут) и последний промпт набран на Mac; со звуком — если последний
промпт пришёл из Telegram или Mac простаивает дольше. «🔕 Тишина» — всё без звука. Порог —
`~/.config/agterm-web/telegram-settings.json`: `{"loudAfterIdleMinutes": 15}`. Закрытая сессия превращается в «📦 … (архив)», тема
закрывается, история остаётся. Без группы бот работает и в личке: ответь на уведомление —
текст уйдёт в его сессию; «📋 Сессии» — выбрать, куда писать без ответа.

Тема «🚀 Новая сессия» (создаётся сама, с закреплённым сообщением) запускает сессии в три
нажатия, сообщение меняется на месте: папка (избранные, недавние, папки открытых сессий или
«📁 Другая…» — путь текстом, только внутри домашней папки) → Claude / Claude — продолжить /
Codex / Терминал → воркспейс (угадан по папке, можно «Создать новый…») → «▶️ Запустить».
Бот открывает в agterm обычную сессию с твоей zsh в этой папке и набирает в ней `claude`
(`claude --continue`, `codex`) — как если бы ты набрал сам: работают твои функции и алиасы
(в том числе обёртка `cswap run`), а после выхода программы остаётся оболочка. Когда у сессии
появится тема, в «🚀» придёт «✅ Запущено: имя → ссылка на тему». То же текстом в любом месте:
`/new ~/work-projects/app [claude|claude-continue|codex|shell] [воркспейс]`.
Избранные папки — `~/.config/agterm-web/launcher.json`: `{"favorites": ["~/work-projects/app"]}`.

Настройка:

1. В [@BotFather](https://t.me/BotFather): `/newbot`, скопируй токен.
2. Сохрани токен (только для себя — иначе бот не запустится):
   ```sh
   install -m 600 /dev/null ~/.config/agterm-web/telegram-token
   pbpaste > ~/.config/agterm-web/telegram-token   # токен в буфере обмена
   ```
3. Для тем: создай группу, в настройках включи «Темы» (Topics), добавь бота и сделай его
   администратором с правами «Управление темами» (Manage topics) и «Закреплять сообщения»
   (Pin messages). Для лички этот шаг не нужен.
4. Перезапусти службу (`./install.sh`), в логе появится `telegram bot enabled`.
5. Привязка: `~/.local/bin/agterm-web -telegram-pair` печатает одноразовый код на 10 минут.
   Отправь боту `/pair <код>` — в группу (в General) или в личку. После пяти неверных попыток
   код сгорает. Пиши от своего аккаунта: от имени группы (анонимный админ) привязка не
   принимается — такие сообщения бот не может отличить от сообщений других админов. Бот
   слушает только тебя и только в этом чате, остальных молча игнорирует.
   Перепривязать — новым `-telegram-pair`.

Состояние (чат, темы, тишина, недавние папки) — `~/.config/agterm-web/telegram.json`, код
привязки — `telegram-pair.json` рядом, оба 0600. Каждое обновление из Telegram выполняется не
больше одного раза: после сбоя служба скорее потеряет одну команду, чем повторит её.
Уведомления и архивация тем при сбоях сети или Telegram повторяются (до ~10 минут). Флаги: `-telegram-token-file`, `-telegram-api`.
Служба раз в 10 с пишет состояние связи с Telegram в `telegram-health.json` (0600, без токена),
и строка меню SwiftBar и низ блока «Лимиты» в веб-панели показывают «Telegram-бот: ✓ на связи»,
«✗ нет связи с 16:01 (таймаут)», «не привязан», «выключен» или «служба не отвечает» (файл старше
2 минут) — это видно, даже когда до Telegram не достучаться.
Всё, что бот пишет в чат, идёт через одну очередь с лимитами Telegram: не чаще раза в секунду
на чат и 20 сообщений в минуту на группу. Токен в логах заменяется на `<token>`, тексты
сообщений не логируются.

## Устройство

- `ctl.go` — вызовы `agtermctl` (tree, session text, session type `--stdin`).
- `limits.go` — лимиты Claude (cswap) и Codex (`GET /api/limits`, `-limits-json`);
  `limitsfmt.go` — текст для строки меню (`-limits-swiftbar`).
- `mirror.go` — зеркало разговоров Claude Code; `mdhtml.go` — Markdown → HTML Telegram;
- `tgbot.go` — Telegram-бот; `tglauncher.go` — тема «🚀 Новая сессия» и `/new`; `telegram.go` — клиент Bot API; `tgoutbox.go` — очередь и лимиты
  исходящих сообщений; `tgstate.go` — состояние и коды привязки.
- `hub.go` — один процесс `agtermctl events` на всех подключённых клиентов, раздача через SSE.
- `main.go` — HTTP, авторизация (cookie из `?t=` + заголовок `X-Agterm-Web` на POST).
- `web/` — интерфейс, вшит в бинарник.

Многострочный текст отправляется как bracketed paste, Enter уходит отдельно через 200 мс.

Лог: `~/Library/Logs/agterm-web.log`. Токен: `~/.config/agterm-web/token` (удали его и
перезапусти службу, чтобы сменить токен).
